# Digital_Recognizer
A simple machine learning project that classifies handwritten digits (0–9) using the MNIST dataset. This project demonstrates image classification using a neural network built with Python and libraries like TensorFlow/Keras or PyTorch.

Features
Input: 28x28 grayscale images of handwritten digits

Output: Digit classification (0 to 9)

Uses a Convolutional Neural Network (CNN) for high accuracy

Training and prediction code included

Total Images: 70,000

Training Set: 60,000 images

Test Set: 10,000 images

Image Size: 28x28 pixels (grayscale)

Labels: Digits from 0 to 9
